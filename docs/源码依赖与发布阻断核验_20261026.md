## 阻断 1：当前公开源码 31/33

以下文件在 OneDrive 完整快照中存在，但由于此前上传请求被安全检查阻止，**未包含于本公开 PR**：

## 阻断 2：两个原版 GUI 覆盖文件尚未纳入公开源码

正式安装快照另有两个 **33 文件候选集以外** 的 GUI 文件：

- `gui/window_military.gui`：包含 `tmm_recruit_select_target`、招募目标及状态反馈按钮。
- `gui/window_menatarms_type_view.gui`：包含 `tmm_recruit_prepare_native` 与 `tmm_recruit_finish_native` 的原版招募衔接按钮。

这些代码和 `common/scripted_guis/tmm_recruit_guis.txt`、`common/scripted_effects/tmm_recruit_effects.txt`、`localization/simp_chinese/tmm_compat_l_simp_chinese.yml` 构成调用链。不能因为逻辑文件已上传，就认定 GUI 招募入口已经被公开版本实现。

两份原版窗口覆盖文件需要再发布权利审查和最小改写可行性评估，**未批准前不上传完整文件**。
